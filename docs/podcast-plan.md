# Podcast企画：街と仕事の実験室 RADIO

## 番組名

# 街と仕事の実験室 RADIO

### サブタイトル

> クラフト、AI、個人事業、音楽、旅。自分の仕事をつくる人の実験記録。

### キャッチコピー

> つくる、稼ぐ、つながる。自分の仕事をつくる人の声。

## 番組説明

会社や一つの収入源だけに頼らず、自分の仕事と暮らしをつくる人たちの話。クラフト、自給自足、業務委託、個人事業、AI、音楽、旅、イベントをテーマに、実際の収入、費用、失敗、工夫、これからの計画を聞く。成功談だけでなく、迷いと次の一歩も記録する。

## 番組の柱

1. **つくる**：クラフト作家、写真家、ダンサー、音楽家、ZINE制作者、小さなブランド。
2. **稼ぐ**：業務委託、個人事業、配達、撮影、SNS運用、イベント収入、複数の仕事。
3. **AIを使う**：企画、制作、営業、顧客対応、イベント、分析。
4. **暮らす**：自給自足、生活費、地域、旅、シェア、会社員との両立。
5. **集まる**：小さなイベント、共同制作、オンラインコミュニティ、案件交換。

## 1回の構成（20〜35分）

- 00:00 オープニング
- 01:00 最近の実験
- 05:00 ゲスト紹介
- 08:00 どうやって仕事をつくったか
- 15:00 収入、費用、失敗、継続条件
- 22:00 AIや道具の使い方
- 27:00 次に試すこと
- 30:00 イベント・コミュニティ案内

金額の公開はゲストの任意とし、代わりに顧客の見つけ方、時間、費用、継続案件、やめたことを聞く。

## 初回エピソード

1. **雇われずに生きる、をいきなり完成させない**：活動の背景、スナップ、ダンス、音楽イベント、AI、配達員紹介、コミュニティ構想。
2. **スナップ写真は仕事になるのか**：`@oshare.dorobous`、撮影、案件、AIで企画へ広げる方法。
3. **音楽イベントはどうやってお金を作るのか**：`@kanalsound`、出演者、会場、告知、費用、AI。
4. **配達、制作、イベントを組み合わせて働く**：配達員紹介を収入実験として扱う。報酬条件と広告性を明示する。
5. **AIで一人の仕事をどこまで増やせるか**：企画、文章、画像、動画、営業、リサーチ、顧客対応。
6. **旅と地域には、まだ知らない仕事がある**：`@pins.zine`、地域の店、人、音楽、仕事。

## AIコーナー

毎回ひとつだけ **「AIに壁打ちしてみた」** を入れる。AIに企画を出させ、ゲストと人間が採用・修正・却下する。AIの回答を正解として扱わず、現場で試した結果を次回へ記録する。

- 静止画投稿 1〜2本

- 記事またはZINEの素材

## 3アカウントとの連携

- `@oshare.dorobous`：ゲストのスナップ、服装、人物の入口。
- `@kanalsound`：エピソード、AI企画、イベント、ゲスト募集。
- `@pins.zine`：収録地、地域、旅、店、暮らしの記録。

## 収益化

初期はイベント集客、ゲストとのコラボ、店舗・ブランド紹介。中期はスポンサー、公開収録、有料イベント、AI企画ワークショップ、限定コミュニティ、ZINE。長期は会員限定エピソード、地域・ブランドとの共同番組、企業向け企画・取材。

提供、協賛、紹介報酬がある場合は、冒頭と投稿文で明示する。

## 最初の30日

- 1週目：番組名、説明、自己紹介回、収録方法を決める。
- 2週目：ゲスト3人を選び、1人目を収録し、短尺を3本作る。
- 3週目：第1回を公開し、Threadsで質問を集める。
- 4週目：公開収録または交流会を行い、反応をコミュニティ企画へ反映する。
