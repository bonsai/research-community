# research-community 素材集

クラフト、自給自足、業務委託、個人事業、AI、プチインフルエンサー案件、音楽イベント、旅と地域を組み合わせ、**雇われるだけに頼らず自分の仕事と暮らしをつくるコミュニティ**の企画素材です。

## 中心コンセプト

> 自分の仕事と暮らしを、自分でつくる。

ここは、成功や簡単な不労所得を約束する場所ではありません。作品、技術、顧客、仲間、コンテンツ、仕組みを少しずつ積み上げ、会社や一つの収入源だけに依存しない生き方を試す実験室です。

## 運用原則

1. AIを主役にしすぎず、実在の人、作品、街、イベントを主役にする。
2. 収入や紹介報酬を保証しない。広告、紹介、協賛の関係を明示する。
3. 小さく試し、数字と失敗を記録し、現場で改善する。
4. 写真、動画、音楽、個人情報、AI入力データの権利と同意を確認する。
5. 「不労所得」は補助的な検索語にとどめ、実態は仕組み型・積み上げ型収入として説明する。

## 想定する最初の実験

**自分の仕事を1つつくる7日間**を開催する。参加者が得意なことを整理し、AIでサービス案を作り、告知し、3人に声をかけ、反応と結果を共有する。
